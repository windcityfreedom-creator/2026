查核原則與資料範圍
  • 事實錯誤、統計口徑與推論問題，和政策取捨分開。缺資料不判為錯誤，尚未履行不直接判為不合理。
  • 保留原始來源、發言時間及必要上下文。摘要不冒充逐字原話；詢問、假設及引述他人不直接當作本人事實主張。
  • 市府澄清與議員批評都是立場來源，不能單憑其中一方宣布另一方錯誤。專業或政策分歧保留支持與反對理由。
  • 每案記錄修正及回應；未查得後續更正不等於沒有更正。可提出原始來源、頁碼及具體修正理由，供後續覆核。
  • 收錄單位是具體議題，不推論人物智力、人格或整體績效。未收錄不代表沒有爭議。

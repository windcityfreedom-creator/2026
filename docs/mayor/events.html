萬聖節ATM遭臉譜男包圍：自由參與與警方處理

事件日期為2023年10月28日。有人裝扮成諷刺高虹安的「新政治提款機」參加市府萬聖節遊行，遭8名臉譜男圍繞。現場報導有阻擋、抽菸等行為，議員與民眾質疑恐嚇或妨害自由；這些質疑與犯罪成立應分開。

10月30日警方表示，裝扮者仍可移動、合照及發糖果，現場加派警力蒐證戒護；抽菸男子已依菸害規定告發，全案報請竹檢調查是否涉及強制罪等。警方說法不等於全部當事人的感受，也不能寫成警方完全沒處理。

高虹安10月30日支持警方，表示現場未有強制、限制自由情況而先蒐證，反對政治語言介入兒童活動；當事人則質疑警方未即時制止，並尋求告發。這是市長與當事人的不同判斷，須與檢察處分分開呈現。

2024年10月25日大紀元報導稱警方於2023年11月6日移送、檢方於2024年1月不予起訴；該文混用簽結與不起訴用語，尚未取得處分原件、案號及再議資訊。聯合報翌日也報導當事人因安全顧慮不參加，並提到不予起訴新聞。此處列「媒體報導未起訴，處分原件及是否確定待核」，不列犯罪前科。

幫派與指使查核：未取得足以確認這8人幫派身分、受誰指示或市府介入的警方／司法原件。穿黑衣、畫臉譜及遭移送都不能直接證明黑道背景。

結論：公開活動中批評政府者能否安全參與、警方如何防止圍堵，值得行政檢討；刑事不予起訴不自動證明活動管理已妥善。須補現場完整蒐證、執法檢討及後續活動安全措施。

晴空匯火災：已有官方指出管理缺失

2024年5月26日晴空匯火警造成兩名消防員殉職。監察院2025年10月公布調查，指出消防入室管制、通訊及公安申報查核有缺失，要求市府與中央改善。這有正式行政調查支持，不是只有政治批評。

市府2025年5月的公開說明提出通訊、安全管制及裝備改善，也稱加強隱蔽工程影像與使用執照前複查。該頁目前擷取受限，先保留機關自述與來源日期；且早於監察院10月結果，不能當成後續已改善結案的證明。

結論：應追蹤監察院要求後的回覆、逾期公安申報追查、裝備交付與演練效果。事故發生在高虹安任職時，2025年改善說明在邱臣遠代理期間；不能把全部建物設計、中央法規及消防機關責任直接等同市長個人刑責。
